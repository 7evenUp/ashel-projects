# Портфолио Артёма

Сайт знакомит с Артёмом как с frontend-разработчиком, показывает личные проекты и рассказывает о его вкладе в проекты Crypton. Режимы Code и Design доступны по прямым адресам и через переключатель в шапке.

## Code

Стартовый разворот объединяет профиль, контакты, список личных проектов и опыт работы в Crypton. Посетитель может открыть целый раздел или перейти к конкретному проекту.

- В разделе личных проектов две главы — Ashel Gym и «Личный Skill». Каждая содержит описание, возможности, стек, иллюстрацию и ссылки. В главе «Личный Skill» доступно копирование команды установки.
- В разделе Crypton семь глав. Каждая показывает название, краткое описание, статус, вклад, задачи и решения, стек и ссылки на проект и исходный код. Полная история разработки открывается в диалоге. Для Academy можно переключаться между веб-платформой и Academy TMA. Ссылка на исходники Academy открывает пояснение об NDA.
- Закладки ведут к главам текущего раздела. Кнопки перелистывания, стрелки клавиатуры и свайпы ведут к соседней главе. Лента «Начало» возвращает к выбору проектов.

## Design

Альбом дизайн-работ открывается по `/#design`. Разворот содержит две карточки под дизайн-проекты. При возврате в Code переключатель открывает разворот, с которого посетитель перешёл в альбом, или начало книги при входе по прямой ссылке.

## Представление и доступность

- На широких экранах страницы образуют книжный разворот, на узких выстраиваются вертикально. Фактуры бумаги, записки и иллюстрации связывают оформление с содержанием глав.
- История браузера и прямые ссылки ведут к соответствующим разворотам, включая отдельный адрес Academy TMA.
- Переключатель, закладки и действия доступны с клавиатуры. Диалоги поддерживают Escape и возврат фокуса. Системная настройка уменьшенного движения учитывается при перелистывании и переключении режимов.
