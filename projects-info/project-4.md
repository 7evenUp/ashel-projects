**Описание проекта**

WEB3 XMS — интерактивная платформа рождественского события для криптосообщества. Пользователи проходили сюжетные главы, выполняли задания на Zealy, накапливали XP и обменивали их на открытие боксов с подарками. Проект объединял промостраницы, личный кабинет, аудиоистории и инвентарь с NFT, промокодами и призами партнёров, включая участие в розыгрыше Ford Mustang.

**Мой вклад**

Выполнял основную работу по развитию фронтенда: адаптивные интерфейсы, игровую логику на стороне клиента, анимации и интеграцию с API.

- Разрабатывал и дорабатывал страницы события, три этапа квеста, просмотр сюжетных эпизодов, профиль и инвентарь.
- Реализовал пользовательский сценарий открытия боксов: проверку доступности, запрос результата, анимацию розыгрыша, показ выигрыша и обновление баланса.
- Интегрировал авторизацию через Crypton ID — по email и через подпись сообщения криптокошельком, включая отдельные мобильные сценарии.
- Подключил синхронизацию аккаунта и XP с Zealy, получение наград, активацию промокодов и запросы на выпуск NFT на TON-кошелёк.
- Дорабатывал аудиоплеер, мобильную адаптацию, состояния загрузки и обработку ошибок; поддерживал проект по мере открытия этапов события.

**Самые интересные фишки**

- **Открытие боксов в формате игровой рулетки.** Прокрутка карточек с замедлением, звуки прохождения призов, оформление редкости и возможность пропустить анимацию. Результат приходит с сервера, а интерфейс останавливается на выигранном предмете.
- **Сюжетный адвент-квест.** Восемь глав с постепенным открытием по расписанию, текстовыми эпизодами, аудиоисториями и индивидуальным цветовым оформлением.
- **Последовательное открытие уровней наград.** Переход от Common к Rare и Legendary по мере участия; интерфейс учитывает доступный пользователю уровень бокса.
- **Единый инвентарь для разных наград.** NFT, промокоды Crypton и призы партнёров имеют свои инструкции, сценарии активации и статусы получения.
- **Необычный сценарий восстановления NFT.** Форма замены NFT без атрибутов: пользователь указывает хеш транзакции сжигания, а фронтенд отправляет запрос на проверку и получает ссылку на замену.

**Стек:** React, TypeScript, Redux Toolkit / RTK Query, Tailwind CSS, Framer Motion, Howler.js, Wagmi / WalletConnect, Vite.
