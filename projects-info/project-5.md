**Nutcracker — платформа для сборки и минта NFT в сети TON**

**Описание проекта**

Веб-приложение экосистемы Crypton, в котором пользователи собирают NFT-Щелкунчика из шести отдельных NFT-деталей. Пользователь подключает TON-кошелёк, выбирает и отправляет детали, отслеживает комплектность набора и запускает минт готового персонажа. Дополнительно предусмотрена поддержка NFT-бустеров.

**Мой вклад**

Разработал клиентскую часть приложения: три основных раздела — инструкцию, коллекцию NFT пользователя и экран сборки и минта.

- Интегрировал TON Connect для подключения кошелька и подтверждения операций.
- Реализовал загрузку NFT через TonAPI, распознавание деталей и бустеров по метаданным и их отображение в интерфейсе.
- Реализовал формирование и отправку транзакций передачи NFT, отслеживание подтверждения в блокчейне и передачу информации о транзакциях на бэкенд.
- Подключил API для отображения прогресса сборки, запуска минта и просмотра полученного персонажа.
- Разработал адаптивный интерфейс, состояния загрузки, ошибок и отсутствия данных, пошаговые диалоги проведения операций.
- Добавил русскую и английскую локализации с синхронизацией языка интерфейса TON Connect.

**Самые интересные особенности**

- **NFT-конструктор из шести деталей.** Голова, корпус, руки и ноги существуют как отдельные NFT. Интерфейс показывает, какие элементы уже собраны и чего не хватает, поддерживает несколько наборов и отмечает использованные детали.
- **Сопровождение блокчейн-транзакции.** Пользователь видит два отдельных этапа: подтверждение в кошельке и ожидание подтверждения в сети. Фронтенд извлекает хеш сообщения из ответа кошелька, находит соответствующую транзакцию через TonAPI и отправляет её на проверку серверу.
- **Учёт переводов, сделанных вне сайта.** Если пользователь отправил NFT напрямую через кошелёк, он может указать хеш транзакции в специальной форме, чтобы передать её на проверку и учесть в прогрессе сборки.
- **Бустеры и праздничный эффект.** Приложение распознаёт отдельные NFT-бустеры и показывает их использование при минте. Успешный ответ на запуск минта сопровождается фейерверком, который учитывает системную настройку уменьшения анимации.

**Стек:** React, TypeScript, Redux Toolkit / RTK Query, TON Connect, TON SDK, Tailwind CSS, Radix UI, i18next, Vite.
