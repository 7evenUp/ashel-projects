**WEB3 XMS — сюжетный Web3-квест с заданиями, XP и NFT-наградами**

Рождественское событие для криптосообщества. Участники проходят восемь сюжетных глав, слушают аудиоистории и выполняют задания в Zealy. Заработанный XP открывает призовые боксы с NFT, промокодами Crypton и наградами партнёров. Промостраницы, история, задания и получение призов объединены в один игровой путь.

**Мой вклад**

Выполнил основную работу по развитию frontend: адаптивные страницы, игровую логику, анимации и интеграцию с API. Разрабатывал три этапа события, профиль, инвентарь и сценарии открытия боксов и получения наград. Поддерживал продукт при переходе между этапами квеста.

**Сюжетные главы, которые открываются по расписанию**

Реализовал восемь эпизодов с датами открытия, текстовыми историями, аудиозаписями и индивидуальным оформлением. Связал отображение заданий и прогресса с данными API и синхронизацией Zealy. Собрал аудиоплеер с управлением воспроизведением, состоянием загрузки и анимированным индикатором звука.

Интегрировал вход через Crypton ID по email и подписи криптокошелька, включая отдельные мобильные формы. Авторизация, привязка Zealy и накопленный XP определяют доступные пользователю действия.

**Открытие боксов с серверным результатом**

Разработал сценарий от проверки доступности бокса до получения награды и обновления баланса. Сформировал анимированную ленту под приз из API, настроил замедление и звук прохождения карточек, показ результата и обновление профиля.

Учёл переход от Common к Rare и Legendary по мере прогресса, нехватку XP, отсутствие привязки Zealy и исчерпание доступных наград. Интерфейс объясняет, что требуется для следующего открытия.

**Разные награды — разные сценарии получения**

Реализовал инвентарь с отдельными действиями для NFT, промокодов и призов партнёров. Подключил выдачу ссылки или кода активации, указание TON-кошелька и запрос на получение NFT. Обрабатывал уже использованные награды, необходимость сначала забрать приз спонсора и ошибки минта.

**Замена NFT без атрибутов**

Собрал отдельный сценарий для пользователей, получивших дефектный NFT: инструкции, ввод хэша транзакции, проверку операции через backend и выдачу ссылки на замену. Перевёл техническую процедуру в понятную форму с обработкой некорректного хэша и серверных ошибок.

**Стек:** React, TypeScript, Redux Toolkit / RTK Query, Tailwind CSS, Framer Motion, Howler.js, Wagmi / WalletConnect, Vite.
