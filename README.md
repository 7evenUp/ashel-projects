# Crypton — дневник разработчика

Интерактивное портфолио Артёма на React, TypeScript, Vite и Tailwind CSS 4. Режим Code открывает книгу с личными проектами и кейсами Crypton. Режим Design открывает отдельный альбом.

## Локальный запуск

Нужны Node.js 22.12+ (также поддерживается 20.19+) и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Сайт доступен по адресу [127.0.0.1:4173](http://127.0.0.1:4173/).

```sh
pnpm build
pnpm preview
```

Сборка находится в `dist/`. Vite формирует относительные URL, поэтому сборку можно разместить в подпапке статического хостинга.

## Навигация

| Адрес | Разворот |
| --- | --- |
| `/` или `/#intro` | Профиль и выбор личных или рабочих проектов |
| `/#personal/ashel-gym` | Дневник тренировок Ashel Gym |
| `/#personal/ashel-front-style` | Личный Skill |
| `/#crypton-id`, `/#nutsfarm` | Главы Crypton по идентификатору проекта |
| `/#academy`, `/#academy/mini` | Веб-платформа Academy и Academy TMA |
| `/#design` | Альбом дизайн-работ |

Главы переключаются закладками, стрелками клавиатуры, кнопками перелистывания и горизонтальными свайпами. Лента «Начало» возвращает к стартовому развороту. Кнопки браузера «Назад» и «Вперёд» восстанавливают разворот из URL. Переключатель Design / Code запоминает последний открытый разворот Code в рамках текущей загрузки сайта.

На узких экранах страницы расположены друг под другом, а закладки прокручиваются по горизонтали. Настройка `prefers-reduced-motion` отключает анимацию перелистывания, смены режима и оформления. Диалог заметок закрывается кнопкой, клавишей Escape или нажатием вне окна и возвращает фокус к элементу открытия.

## Структура

| Где | Что находится |
| --- | --- |
| `src/App.tsx` | Оболочка сайта, выбор разворота, заголовок вкладки и диалог заметок |
| `src/routing.ts` | Разбор и формирование адресов, порядок глав и выбор варианта проекта |
| `src/components/Book/` | Навигация по книге, обработка клавиатуры и свайпов, закладки, обложка и счётчик глав |
| `src/components/PageTurn.tsx` | Визуальные копии страниц для анимации перелистывания |
| `src/components/IntroSpread/`, `PersonalSpread/`, `Spread.tsx`, `DesignSpread.tsx` | Стартовый разворот, личные и рабочие главы, альбом |
| `src/data/` | Профиль, проекты, композиции, иконки и сгенерированные заметки |
| `src/styles.css`, `src/book-materials.css` | Базовые стили, фактуры книги и анимация страниц |
| `public/assets/` | Шрифты, иконки, изображения проектов и фоновый декор |

## Обновление контента

- Личные проекты и контакты редактируются в `src/data/profile.ts`. Карточка личного проекта задаёт описание, стек, внешние ссылки, иллюстрацию и при необходимости команду установки.
- Список рабочих проектов и порядок глав задаёт `src/data/projects.ts`. Здесь находятся короткие описания, вклад, задачи, стек и варианты Academy.
- Для каждой рабочей главы в `projects-info/` есть файл `<id>.md`, например `academy.md`. Первые три строки задают `Исходный код:`, `Деплой:` и `Статус:`. Допустимые значения статуса — `активный проект` и `проект в прошлом`. Значение `NDA` открывает пояснение об исходном коде.
- `pnpm content` обновляет `src/data/source-notes.json` из Markdown. Команда запускается автоматически перед разработкой, сборкой и модульными тестами. При добавлении рабочей главы задайте её композицию в `src/data/compositions.ts` и иконку в `src/data/favicons.ts`.
- Период работы в Crypton начинается в ноябре 2022 года. Месяц окончания вычисляется при загрузке сайта по московскому времени.

## Проверки

```sh
pnpm test
pnpm typecheck
pnpm exec playwright install chromium
pnpm test:browser
```

Vitest проверяет адреса, соответствие заметок проектам, композиции и расчёт периода работы. Playwright проверяет настольную и мобильную версии, включая навигацию, историю, анимации, диалоги и адаптивную раскладку. Снимки сохраняются в `test-results/`.
