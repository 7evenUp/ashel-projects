# Crypton — дневник разработчика

Интерактивное портфолио Артёма. Стартовый разворот объединяет личную и рабочую страницы с компактными кнопками проектов. Кнопка «Открыть личные проекты» ведёт к главам Ashel Gym и «Личный Skill», а «Открыть рабочие проекты» — к семи главам Crypton и отдельному представлению Academy TMA. Каждый раздел имеет свои закладки и перелистывание. Vite, React, TypeScript и Tailwind CSS 4.

## Запуск

Требуется Node.js 22.12+ (или 20.19+).

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:4173. Команда `npm start` также запускает режим разработки.

```sh
npm run build
npm run preview
```

Статическая сборка находится в `dist/`. Относительные адреса позволяют размещать её в подпапке хостинга.

## Управление

- Закладки переключают проекты; кнопки, стрелки клавиатуры и горизонтальные свайпы перелистывают главы.
- Горизонтальная лента «Начало» на левом боку книги возвращает к личному и рабочему развороту. Он также открывается по `/#intro` и по адресу без главы.
- Прямые адреса, например `/#personal/ashel-gym`, `/#personal/ashel-front-style`, `/#nutsfarm` и `/#academy/mini`, и история браузера сохраняются.
- Диалог полных заметок закрывается кнопкой, Escape или нажатием вне окна. Фокус возвращается на кнопку открытия.
- На телефоне страницы располагаются вертикально. Учитывается настройка уменьшения анимации.

## Контент и оформление

- `src/data/projects.ts` — тексты разворотов и тематические данные.
- `src/data/profile.ts` — имя, роль, опыт, GitHub и список личных проектов со ссылками на превью и код. Новые личные проекты добавляются в `personalProjects`.
- `src/components/IntroSpread/` — стартовый разворот с двумя игровыми режимами.
- `src/components/PersonalSpread/` — развороты личных проектов с описанием, возможностями, стеком и внешними ссылками.
- Ashel Gym иллюстрируется тренировкой, календарём и графиком прогресса с ассетами из приложения. «Личный Skill» — файлом SKILL.md, AI-агентом и примером компонента. Команду установки можно скопировать кнопкой.
- Период работы в Crypton начинается с ноября 2022 года. Последний месяц вычисляется один раз при загрузке сайта по московскому времени.
- `src/data/compositions.ts` — постоянные углы карточек и позиции декора всех восьми представлений.
- `projects-info/` — полные исходные заметки. Генератор обновляет `src/data/source-notes.json` перед разработкой, сборкой и тестами. Ручное обновление: `npm run content`.
- `src/components/` — React-компоненты, JSX-иллюстрации и диалог заметок.
- `src/styles.css` — Tailwind, фактуры, книжные эффекты и адаптивное оформление.
- `public/assets/` — локальные шрифты и favicon. Иконки скопированы из предоставленных репозиториев; Academy TMA использует свою иконку приложения. Исходные репозитории не нужны для сборки.

Статусы и ссылки сохранены по предоставленным материалам. Исходники Academy закрыты по NDA.

## Проверки

```sh
npm test
npm run typecheck
npx playwright install chromium
npm run test:browser
```

Проверяются контент, адреса, favicon, композиции, навигация, история, диалоги, свайпы и уменьшенная анимация. Браузерные тесты проходят на широком и мобильном экранах и сохраняют снимки восьми представлений в `test-results/`.
