# Crypton — дневник разработчика

Сайт-портфолио по `PRD.md`: интерактивная книга с семью проектами Crypton. Каждый разворот включает описание, вклад, необычные кейсы, стек, статус и ссылки. У Academy есть отдельные представления веб-платформы и Telegram / Base.

## Запуск

Требуется Node.js 20 или новее. Внешние зависимости не нужны.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Можно задать другой порт через переменную `PORT`.

## Управление

- Закладки над книгой переключают проекты.
- Кнопки «Назад» и «Дальше», стрелки клавиатуры и горизонтальные свайпы перелистывают главы.
- Каждая глава имеет собственный адрес, например `/#nutsfarm` или `/#academy/mini`. Работают история браузера и прямые ссылки.
- «Все заметки о проекте» открывает полный исходный рассказ. Окно закрывается кнопкой, Escape или нажатием вне него.
- На телефоне страницы разворота расположены одна под другой. Учитывается системная настройка уменьшения анимации.

## Файлы и контент

- `site/dist/` — готовый статический сайт, который можно разместить на любом статическом хостинге.
- `site/dist/projects.js` — краткие тексты разворотов, оформление и настройки проектов.
- `projects-info/` — исходные полные описания. После изменений выполните `npm run content`, чтобы обновить полные заметки и ссылки.
- `site/dist/art.js` — SVG-иллюстрации и значки; `style.css` — оформление и адаптивность; `app.js` — навигация.
- Шрифты взяты из локальной кодовой базы Academy, предоставленной для проекта. Сетевых загрузок шрифтов нет.

```sh
npm test
```

Проверки контролируют полноту проектов, сохранность исходных текстов, соответствие ссылок и статусов, наличие обоих вариантов Academy и отметку NDA.

Статусы проектов сохранены по предоставленным материалам. Доступность внешних деплоев и репозиториев не гарантируется самим портфолио.
